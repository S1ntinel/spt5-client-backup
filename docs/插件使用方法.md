## 实际安装情况

| 插件／组件 | 原环境 6969 | 地图环境 6979 | 用途与操作 |
|---|---|---|---|
| SPTushonka 系列、sptushonka-prepatch | 有 | 有 | SPT 基础客户端兼容组件，自动加载，无需单独开关 |
| RaidHideoutGuard | 有 | 有 | 对局初始化的藏身处条件监听兼容修复，自动生效，无热键 |
| SPTMap | 无 | 有 | 全屏地图、小地图、自身位置、方向和楼层显示 |
| ZeroScavCooldown | 有 | 无 | 原环境 SCAV 冷却持续归零，服务器启动时加载 |
| ScavSettlementFix | 无 | 有 | 普通存活 SCAV 撤离库存同步及新版全部出售请求兼容修复 |
| Dynamic Maps 1.2.1 | 未安装 | 未安装 | 单独存放在顶层 `DynamicMaps-1.2.1`，不是当前运行的地图插件 |

`Newtonsoft.Json.dll` 是 SPTMap 附带依赖，不是另一个需要操作的插件。未见独立的 BepInEx.ConfigurationManager 安装项，因此不要假定 F12 配置面板可用。

## SPTMap 操作

| 操作 | 按键 |
|---|---|
| 打开／关闭全屏地图 | M |
| 开关小地图 | 小键盘 0 |
| 全屏缩放 | 鼠标滚轮；小键盘 8 / 5 |
| 小地图缩放 | 全屏关闭时，小键盘 8 / 5 |
| 恢复全图与自动跟随 | 小键盘 2 |
| 全屏平移 | 鼠标中键拖动或方向键 |
| 回到玩家中心 | Home |
| 上／下一层 | 小键盘 7 / 4 |
| 恢复自动楼层 | 小键盘 1 |
| 上／下一张地图 | 小键盘 6 / 9 |
| 恢复当前地图自动选择 | 小键盘 3 |
| 校准地标日志 | 小键盘小数点 |

没有数字小键盘时，M 和鼠标仍可使用；这份说明不承诺可以在现有配置文件中重绑写死的快捷键。

## 原包的地图配置

文件：`_SPTMap_Test/BepInEx/config/com.sptmap.plugin.cfg`。退出游戏后编辑并重新启动，先备份旧配置。

| 项目 | 原包实际值 |
|---|---|
| 小地图 | 开启 |
| 锚点 | 右上角 |
| 最大边长 | 220 像素 |
| 右边距／顶边距 | 10／80 像素 |
| XYZ 坐标 | 开启 |
| 任务地点、锁门、开关 | 开启 |
| 精确任务物品、敌方 PMC／SCAV／Boss、友军、尸体 | 关闭 |
| 空投、BTR、普通容器、地埋点、心愿单物品、丢弃背包 | 关闭 |
| 性能日志 `Log performance` | **true**（原包保留 QA 设置，并非发行默认 false） |

顶边距 80 是按当时 2560×1440 画面避开剩余时间、对齐撤离行调整的；其他分辨率应按实际画面检查。修改这项只需调整 `Vertical padding`，不要覆盖整份个人配置。

不需要性能诊断时，可在退出客户端后把 `Log performance = true` 改为 `false`，减少周期性诊断日志；本次上传没有代改原包。

本次适配版排除了 F9 写入面板、传送、画外 ESP 和伤害浮字；不能通过配置重新打开这些已移除路径。

## 后台修复插件

- `RaidHideoutGuard`：位于 `BepInEx/plugins/LocalRaidFix`。修复已确认的一类初始化空引用，不能代表所有进图失败都修复。
- `ZeroScavCooldown`：位于原环境 `SPT_Runtime/user/mods/ZeroScavCooldown`。有界面冷却显示时仍应以实际是否能再次选择 SCAV 为准。
- `ScavSettlementFix`：位于地图环境 `SPT_Runtime/user/mods/ScavSettlementFix`。针对各地图共用结算流程；已有 16 项隔离后端断言通过，未把后端验证等同于全地图游戏验收。

停用某个插件时，先退出对应游戏和服务端，只将该插件的独立目录移至环境外的备份目录。不要删除 SPTushonka 基础组件或覆盖整个 BepInEx。回退后旧故障可能重新出现，已经改变的存档不会自动恢复。

## 顶层额外工具

`youhua` 包含 Process Lasso、RAMMap、测试程序和进入 BIOS 的快捷方式。它们是原快照保留的额外文件，不是运行 SPT 的必要步骤；不要把 BIOS 重启或压力测试工具当作一键启动入口。未对这些第三方工具重新做功能验证或更改授权。
