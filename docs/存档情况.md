## 备份和恢复

1. 正常退出游戏、Launcher 与对应服务器。
2. 复制整个对应环境的 `SPT_Runtime/user/profiles` 到带日期的新备份目录。
3. 需要回退时先备份当前版本，再只恢复目标账号文件；不要将原环境与地图环境的整个用户目录互相覆盖。
4. 重启同一环境，核对账号、等级、仓库物品和任务状态。

恢复旧快照会回退之后的游戏进度。新版本 SPT 是否接受旧存档需要另行验证；本次未执行升级迁移。
