## 下载与空间准备

仓库已公开；Release 正式发布后可直接下载。需要 Windows x64、7-Zip；使用校验和预检工具还需要 Python 3.11 或更新版本。

分卷共约 80.74 GiB，完整解压文件约 159.63 GiB。保留分卷并直接解压时建议至少 250 GiB 空闲空间；若额外合并保存一份完整 7z，再预留约 81 GiB。

已安装并登录 GitHub CLI 后，在 PowerShell 执行：

```powershell
gh release download archive-2026-10-04 --repo S1ntinel/spt5-client-backup --dir D:\SPT-Download --pattern 'LIxian-BaN.7z.*' --pattern manifest.json --pattern SHA256SUMS.txt
```

如果 Release 仍是 Draft，说明上传尚未完成，不要将部分分卷作为完整备份使用。

## 校验与解压

在克隆或下载的本仓库目录执行：

```powershell
python .\tools\verify_parts.py D:\SPT-Download
```

预期：44 个分卷的大小和 SHA256 均匹配，最后出现 `PASS: all parts and original archive SHA256 match`。该工具顺序读取分卷，计算与原包相同的完整 SHA256，不生成另一个 80.74 GiB 文件。

全部分卷必须在同一目录，文件名及编号保持不变。使用 7-Zip 打开 `LIxian-BaN.7z.001`；也可执行：

```powershell
& 'C:\Program Files\7-Zip\7z.exe' t 'D:\SPT-Download\LIxian-BaN.7z.001'
& 'C:\Program Files\7-Zip\7z.exe' x 'D:\SPT-Download\LIxian-BaN.7z.001' '-oD:\'
```

预期输出目录为 `D:\LIxian BaN\EFT5.0`。目标若已有同名环境，改用新的空目录，不覆盖现有进度；迁移路径需同时调整下述配置。

## 运行库

服务端 `SPT.Server.runtimeconfig.json` 要求 `Microsoft.NETCore.App 10.0.0` 和 `Microsoft.AspNetCore.App 10.0.0`；需要 x64 的 .NET 10 兼容修订版本。既有环境曾用 10.0.9 验证启动。

```powershell
dotnet --list-runtimes
python --version
```

应同时看到上述两种 .NET 10.x 运行库。运行库缺失时通过微软官方安装程序补齐；不要替换服务器核心 DLL。

## 恢复一键启动依赖

压缩包中的两份 `SPT_Runtime/Start-SPT.ps1` 都引用：

```text
C:\Users\S1ntine1\Documents\Codex\2026-10-02\d-lixian-ban-eft5-0-spt-2\tools\isolation\SPT-Preflight.ps1
```

压缩包没有包含这套工具。缺失时会显示 `SPT preflight tool is missing; startup refused.`。

有两种恢复方式：

- 恢复原机器布局：把本仓库的 `tools/isolation` 四个文件复制到上述位置。已有文件时先比较，避免覆盖后来修改的工具。
- 使用新工作目录：先备份两份 `Start-SPT.ps1`，将各自的 `$sptGuard` 指向本仓库 `tools/isolation/SPT-Preflight.ps1` 的实际绝对路径。

`tools/isolation/policy.json` 中的 `spt_roots` 必须写入实际原环境和地图环境根目录；`protected_roots` 必须保留并正确指向本机官方 Live 安装目录。不要把 Live 目录添加到 SPT 白名单，也不要删除预检调用来绕过错误。

若解压位置改变，还需同步：

1. 各环境 `SPT_Runtime/user/Launcher/LauncherSettings.json` 的 `GamePath`，或通过对应 SPT Launcher 的路径设置修改。
2. 两个 `.lnk` 的目标参数及起始位置。原包两者实际均调用地图环境的 `Start-SPT.ps1`，名称为“Launcher”的入口也会启动服务器。

## 启动与退出

1. 先正常退出官方 Live 游戏；选择原环境或地图环境之一。
2. 使用修复依赖后的快捷方式。推荐地图环境 `127.0.0.1:6979`，选择 SPTMap-QA 或 AllMaps-QA。
3. 原环境端口为 `127.0.0.1:6969`，其 Launcher 保存的服务器列表为空，需要首次手动添加这个地址。
4. 等服务端启动完成，再由 SPT Launcher 点击开始游戏；不要直接双击 `EscapeFromTarkov.exe`。
5. 结束后先在游戏内正常退出，再关闭 Launcher，最后正常停止服务端，避免强杀时丢失保存。

服务端启动脚本会把输出写入对应 `SPT_Runtime/user/logs/one-click-server.stdout.log` 和 `.stderr.log`，最长等待端口就绪 90 秒。它会拒绝其他进程占用该端口的情况。

## 启动成功判据

对应端口由正确环境的服务器监听、Launcher 路径正确、选中的账号与环境一致，并能进入菜单。进入菜单不等于所有地图和 SCAV 结算均完成验收。
