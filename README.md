## 使用顺序

1. 阅读 [下载、校验与启动](docs/使用方法.md)，下载同一 Release 的全部分卷并校验。
2. 解压到独立离线目录。原包保存的路径为 `D:\LIxian BaN\EFT5.0`。
3. 恢复启动前预检依赖；原包里缺少其引用的外部 Codex 工具，不能只解压就假定一键启动可用。
4. 选择正确服务端和 [现有存档](docs/存档情况.md)，再从 SPT Launcher 启动。
5. 地图操作及后台补丁说明见 [插件使用方法](docs/插件使用方法.md)。

## 重要边界

- 本仓库已公开，Release 在上传及校验完成后公开发布。原包包含个人存档、日志、备份和第三方程序。
- 原包包含两套完整环境及 `_SettlementRegression` 回归副本；回归副本不作为日常入口。
- `DynamicMaps-1.2.1` 是单独保存的原插件包；实际地图环境使用 SPTMap，勿再叠加安装。
- 地图环境未包含 `ZeroScavCooldown.dll`。存档当前冷却值为 0，不代表以后始终为 0 秒。
- SCAV 结算补丁有后端回归验证，最终游戏内验收未在本次上传中重新执行。
- Live 正版授权错误属于另一项排查，不能通过这个离线备份修复。所有文件必须远离官方 Live 安装目录。

## 附带文件

- `tools/verify_parts.py`：流式校验全部分卷和重建后的逻辑原包 SHA256，不修改分卷。
- `tools/isolation/`：此前使用的启动预检依赖副本，供恢复原包缺失的外部依赖；路径策略需要与实际机器一致。
- `archive-info.json`：本地原包与清单信息，不代表远端上传已经完成。
- Release 处于 Draft 时表示仍在上传或核验；以正式发布的 Release 为完整交付。
